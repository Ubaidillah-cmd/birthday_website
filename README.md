# 🎂 Birthday Website – Premium Elegant Edition

## Struktur Folder
```
birthday-website/
├── index.html
├── README.md
└── assets/
    ├── css/
    │   └── style.css
    └── js/
        └── script.js
```

## Cara Pakai
1. Buka `index.html` di browser modern (Chrome, Firefox, Edge, Safari)
2. Ganti **"Namamu"** di `index.html` dengan nama asli
3. Ganti tanggal **`25 Mei 2026`** sesuai tanggal ulang tahun
4. Ganti foto di **Hero Section** — ubah URL `https://i.pravatar.cc/400?img=47`
5. Ganti foto **Gallery** — ubah URL `picsum.photos/seed/...` dengan foto asli
6. Edit teks **Timeline** sesuai kenangan nyata
7. Edit **Surat Spesial** di `#message` section
8. Target **Countdown** ada di `script.js` → fungsi `startCountdown()`
